## Selected Work

### [Multi AI Meeting Room](https://github.com/Schromeo/multi-ai-meeting-room)
A collaborative platform for orchestrating and coordinating multiple AI agents in real-time interactions.

- Multi-agent conversation coordination and state management
- Real-time communication and message routing
- Extensible agent framework for diverse AI capabilities

### [SledTrace](https://github.com/Schromeo/SledTrace)
A local-first platform for tracing, evaluating, and debugging RAG workflows.

- Python tracing SDK, Go collector, SQLite persistence, and React dashboard
- Deterministic diagnostics for retrieval, grounding, conflict, and numeric failures
- Docker Compose quickstart and API-key-free reference scenarios

### [VecDB](https://github.com/Schromeo/VecDBMVP)
A from-scratch persistent vector search engine implemented in C++.

- Hierarchical HNSW and brute-force ground truth
- Metadata filtering, concurrency, persistence, and Recall@k benchmarks
- 0.96–0.99 recall@10 at approximately 0.3 ms on 200K vectors

### [Distributed KV Store](https://github.com/Schromeo/DistributedKVStoreMVP)
An educational distributed key-value storage system exploring replication, consistency, and failure handling.
